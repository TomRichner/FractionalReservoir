# Feature requests

**These are not to-do items for an agent.** They are notes, directed by
Tom, about features that may be worth adding later and for which there is
no time now. An agent reading this file should not start work on any of
them unless Tom asks for that feature in the conversation. Until then
they are context only.

This file is separate from `docs/ISSUES.md`, which tracks work that has
been decided on. An entry moves from here to there only when Tom says so.

Each entry says what is wanted, why, and what is known so far. Newest
first. Number entries FR-001, FR-002, and so on, and give the date the
note was made.
