# Stimulation of the frozen IED-like network

October 5, 2026. First stimulation test of the run13 working base
(`ied_base_config.m`). The question is whether a sustained uniform input, the
same kind of drive used for the hyperexcitable bursting figure, reduces the
localized candidate events and changes the module-mean spectrum, as the
clinical CSCS figures (`Stim-Analysis-Figs/Fig_Tica_Main.png`,
`Fig_TicaFullband_PSD_Supp.png`) report for candidate IEDs and SOZ power.

This is a model experiment on one hand-selected network family. Eight network
realizations give a sense of robustness across connectivity and noise draws;
they do not validate the network as a clinical IED model.

## Protocol

- Network: `ied_base_config` physics, unchanged (350 neurons, five 70-neuron
  modules, one SFA timescale per neuron, E-only single-component STD, Wiener
  amplitude 0.025). Built by `ied_build_network`, which repeats the
  construction in `run_ied_experiment` but accepts an input configuration;
  `run_ied_experiment` itself still asserts zero input and is the record of
  the pilot.
- Realizations: network seeds 42 (the frozen base), 73 (the run15 check), 101,
  137, 211, 307, 409, 503. The Wiener seed is offset by the same amount as the
  network seed from the base pair (224779 at seed 42).
- Input: `dc_staircase_stimulus` with levels [0, A], each held 60 s, no ramp,
  no added white noise (the Wiener process is already in the model). The 10-s
  warm-up before t = 0 is unstimulated. Amplitudes A = 0.05, 0.10, 0.20, 0.30,
  one simulation each per seed, so the unstimulated half is replicated across
  amplitudes within a seed.
- Analysis windows: 10 to 60 s (no stimulation) and 70 to 120 s (stimulation),
  the first 10 s of each half discarded. Both windows are 50 s, like the
  pilot observation interval.
- Lyapunov tracking is off (`lya_method = 'none'`); each run takes about 9 s.
- Candidate events: detector v1 (`ied_detect_events`) run separately on each
  window, so each window's threshold is its own median plus the larger of
  3 robust SD or 0.12 a.u. A fixed-criterion control re-applies the
  no-stimulation excursion criterion (threshold minus median, per neuron) on
  the stimulated window's own median, so a uniform DC offset is not itself
  counted; a plain fixed absolute threshold was tried first and counted the
  offset as hundreds of events per minute, which is why the criterion is
  re-centred. The detector gained an optional sixth argument for this; its
  default behaviour is unchanged.
- Spectra: the five module-mean dendritic states are the "channels". Welch
  PSD per channel (10-s Hamming windows, 50% overlap, 200-Hz plotting rate),
  averaged arithmetically across modules, as the clinical SOZ contacts were.
  Band power is the trapezoidal integral over delta (1–4 Hz), theta (4–8),
  alpha (8–13) and beta (13–30), expressed as 10·log10(stim / no stim).
  Model time is nominal: tau_d = 0.1 s puts almost all power below 3 Hz, so
  the band labels are a convenience for comparison, not a calibration.
- Correlation: zero-lag Pearson correlation of 10-Hz-subsampled dendritic
  states, averaged over within-module and between-module neuron pairs.
- Adaptation state: mean rate, SFA feedback (c·Σa / n) and mean synaptic
  resources (product of the E-output depression variables), averaged over
  each window.

Scripts: `ied_stim_experiment` (simulate and save), `fig_ied_stim` (plot from
saved files). Data in `data/IED_model/stim_20261005/` (ignored by git; seed 42
also keeps the full x and r), figure and statistics in
`figs/IED_model/stim_20261005/` (ignored). Committed copies:
[statistics](stim_2026_10_05_stats.md) and the
[per-window summary table](stim_2026_10_05_summary.csv) without the PSD
vectors.

## Results

Amplitude 0.10 is used for the detailed panels. It is the smallest tested
level at which every realization's event rate fell, and its rate ratios
(median 0.39, range 0.12 to 0.87) bracket the clinical candidate-IED ratios
(median 0.68, range 0.22 to 0.97). At 0.20 and 0.30 events are nearly or
entirely abolished in most realizations, which the clinical data do not show.

| Input level | Events/min, median [min, max] | Fixed criterion |
|---|---|---|
| 0 | 18.6 [9.6, 36.0] | 18.6 [9.6, 36.0] |
| 0.05 | 13.2 [2.4, 26.4] | 10.8 [1.2, 21.6] |
| 0.10 | 7.2 [1.2, 18.0] | 5.4 [0.0, 18.0] |
| 0.20 | 2.4 [0.0, 10.8] | 0.6 [0.0, 16.8] |
| 0.30 | 0.0 [0.0, 3.6] | 0.0 [0.0, 9.6] |

At 0.10, across the eight realizations:

- Mean rate rose from 0.129 to 0.163 (+28%), SFA feedback from 0.064 to
  0.082 (+28%) and synaptic resources fell from 0.614 to 0.562 (−8%). Activity
  is preserved and adaptation is engaged; saturation stays near 10^-4.
- Delta power fell by a median 2.3 dB (−4.8 to 0.0; below zero in 7 of 8).
  Theta, alpha and beta changed by less than 1 dB with no consistent sign;
  the model has almost no power there. The PSD change is therefore a
  low-frequency reduction, not the broadband reduction seen in five of seven
  patients.
- Within-module correlation fell from 0.249 to 0.197 (median change −0.055,
  all eight negative); between-module correlation stayed near zero. This is
  the opposite sign to the clinical SOZ–SOZ correlation change (median +0.12),
  as the current manuscript already notes for the bursting network.
- Event waveform FWHM narrowed slightly (0.239 to 0.217 s) and median
  recruitment was unchanged (0.09 to 0.08).

## Caveats

- One network family, eight realizations, one detector. The detector's
  relative threshold adapts to each window's variability; the fixed-criterion
  control gives the same direction at every level.
- DC input, not 2-Hz pulses. The manuscript's Methods already describe the
  model stimulation as a constant uniform input chosen to avoid pulse
  artifacts; a pulsed version is listed in `Future_investigations.md`.
- Nominal time units; band labels are for side-by-side reading only.
