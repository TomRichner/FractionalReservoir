For agents building or testing: nobody is bound by this chart. A step takes as long as doing it properly takes; never shorten, skip, reorder or hurry work to match a bar. A step that runs longer than its estimate is not a problem, only an estimate to correct at the next update. Quality comes first and the plan is the guide.

How to read it

A_0c_T
Task code stage_step_kind: block A, step 0c of the plan, a Test. Kinds: P plan, B build, T test, U user (nothing proceeds until Tom has decided, reviewed or talked it through). The kind is fixed; the status “waiting on Tom” below changes as work moves. A trailing number (A_4_B2) separates several tasks of one kind in one step. Rough blocks number their steps 0, 1, 2… with 0 the planning step.
✓ done
finished; drawn at its actual times
▶ running
under way now; a dotted tick marks where its estimate ended if it runs longer
○ planned
not started; placed after what it waits for
◆ waiting on Tom
needs Tom: a decision, a review, or a run only Tom starts
dashed
rough: not planned in detail, duration a guess (≈)
now
when this page was generated
grey “idle” column
a past stretch with no recorded work, drawn narrow

Hover over (or tab to) a bar or a row for what the step does, who does it, what it waits for and how it is checked.
